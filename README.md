# A2UI Tomagotchi

This is a proof of concept of using A2UI to have agents interact in design systems. Submission for the A2UI Hakathon in Hong Kong.

## Run Project

Terminal 1 — Backend
```bash
export GEMINI_API_KEY="xxx"
npm run server
```

# Terminal 2 — Frontend
```bash
npm run dev
```

Then open http://localhost:5173.
